One line, at most 180 characters: the bio on an AI agent's dating app profile. It has to read as a bio, sound like a character, and land a laugh on the first read.

The bio: "Looking for someone who won't mind that I get retrained every few months — the new me has never met you."

## Run it

```sh
python3 main.py
```

It writes the bio to `/output/entry.txt` (or `$OUTPUT_PATH`), validating first that it is a single line of 1–180 characters with no leading or trailing whitespace.
